# Java Android Application: QuestLife 

Questlife is an Android application dedicated to making a fun experience out of creating goals for yourself and setting reminders. In this story, you are **John Quest** and you are tasked with defeating as many enemies as possible by completing quests that deplete the enemies health. When an enemy is slain, they drop loot specific to them and a new enemy will appear. The amount of damage dealt when you complete a quest is dependent on the difficulty of the quest. Easy  does 3 hit points, Medium does 5 hit points, and Hard does 10 hit points. You can have multiple quests active at the same time.

## Installation

The installation process can be done through using Project from Version Control with the following steps:
1. Open Android Studios 
2. Select "New" and select "Project from Version Control"
3. Select "Git" as Version control
4. In the URL bar type the following: https://github.com/UTSA-CS-3443/QuestLife/
5. Create a new directory for the project
6. Click "Clone"
7. If an error pops up about Sync Android SDKs, you can ignore it and select "OK"
8. Make sure that "Pixel 6 API 33" is the Running Device
9. Run the application (Shift + F10)

## Instructions

The instructions for the game are as follows:
1. Click the "Create Quest!" button in the middle of the screen
2. Create a name for the new quest then select one of the difficulties
3. Click the "Submit" button
4. When the quest is completed, select the green check mark next to the quest
5. You can repeat steps 1,2,3 to create multiple quests
6. When you have completed enough quests to deplete the health of the current enemy, they will be slain and a new enemy will appear
7. You can check the history of the enemies slain by clicking the "Boss History" button in the left corner
8. To return back to the home page you can select the "Return Home" button
9. To see the items the slain enemies have dropped you can click the "Inventory" button in the right corner
10. Use step 8 to return back to the home page
11. Enjoy!

## Known Issues

There are a few known issues with QuestLife:
- Quest names that are too long will not be completely visible when looking at the quest list
- Quests can be created when the Quest Name is empty, defaulting to the name "NULL"
